# Maple shared skills

This public repository holds reusable skills contributed by Maple deployments.
Each skill belongs in `skills/<name>/SKILL.md`, with supporting references or
scripts alongside it when needed. Include practical, reusable instructions and
verify any included commands.

Propose learned skills and changes through a pull request. A human reviews and
merges each contribution; agents must not merge their own proposals or push
directly to the protected main branch. Include only material appropriate for a
public repository: never publish credentials, private conversations, personal
data, confidential documents, or authoritative audit records.

Deployment-specific memories, instructions, code and scripts remain in the
deployment's workspace repository or persistent volume as appropriate.
