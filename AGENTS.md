# Shared skill contributions

This repository is public. Propose changes through a pull request and leave
review and merge to a human. Never push directly to protected `main` or merge a
proposal yourself. Verify that every contribution is safe to publish, including
its history and supporting files.

Add concise, reusable skills in `skills/<name>/SKILL.md`. Prefer client-specific
preferences or processes and verified lessons; do not restate general knowledge
already available to the model. Do not include credentials, private user data,
conversation histories or confidential material.
